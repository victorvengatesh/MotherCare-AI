# MotherCare AI - Roadmap

## Phase 1: V1 Scaffold (Current)
- [x] Basic React frontend with Vite.
- [x] FastAPI backend with analysis placeholder.
- [x] Project organization into `frontend/`, `backend/`, `model/`, `data/`.
- [x] Clean, scalable folder structure.

## Phase 2: Enhanced Analysis
- [ ] Integration of a real NLP model for symptom analysis.
- [ ] Integration of a computer vision model for image classification.
- [ ] Basic SQLite database for storing anonymized analysis history.

## Phase 3: Advanced Features
- [ ] **Multilingual Support**: Support for Spanish, French, and local dialects.
- [ ] **Voice Interaction**: Voice-to-text for symptom reporting.
- [ ] **User Accounts**: Optional authentication for saving history.
- [ ] **Doctor Connect**: Exportable PDF summary of AI findings for medical professionals.

## Phase 4: Production Polish
- [ ] Containerization (Docker).
- [ ] CI/CD pipelines.
- [ ] Comprehensive automated testing (unit, integration, E2E).
